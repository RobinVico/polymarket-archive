# 🌤️ 天气 bot — Polymarket 每日最高温市场

> 独立项目, 专用新钱包, 跟 ~/polymarket (5051) / ~/polymarket-auto (5052) 完全隔离。
> Dashboard: http://localhost:5053

## 原理 (一句话)

日落之后气温只降不升 → 当日最高温已成事实 → 但对应档位还挂在 0.9x → 买入吃 1~5% 的确定性差价, 次日结算兑现。

## 策略规则 (2026-07-12 用户定, 激进档)

| 项 | 值 |
|---|---|
| 触发时刻 | 当地日落即下单 (成都类日落晚于市场 20:00 名义截单 → 提前到截单前 10 分钟) |
| 降温确认 | 现温比当日最高低 ≥1.0°C 才下单 (防夜间暖锋反攻) |
| 买价区间 | 0.90 ~ 0.995 (低于 0.90 = 市场不认同我们的数据, 不买; 高于 0.995 利润太薄) |
| 市场共识 | 我们算的档必须 = 市场最贵的档, 不一致宁可不下 (数据口径保险丝) |
| 单笔 / 日限 | $5 / 市场, 每日 $30 |
| 城市 | 上海 / 北京 / 深圳 / 成都 / 武汉 / 香港 (台北有市场但默认关) |

## 数据源 (跟结算源一字对齐)

- **大陆城市**: 结算 = Wunderground 机场站页 (本质 METAR) → 我们读 aviationweather.gov 同一批 METAR, 整数 °C。站点: 上海浦东 ZSPD / 北京首都 ZBAA / 深圳宝安 ZGSZ / 成都双流 ZUUU / 武汉天河 ZHHH。
- **香港**: 结算 = 天文台总部"当日绝对最高" (Daily Extract, 0.1°C 精度) → 我们读 HKO 官方 1 分钟数据 (latest_1min_temperature.csv, 同站同精度)。
- **香港取整 = floor** (实证: 2026-07 官方 33.5°→33 档 / 32.6°→32 档 / 31.6°→31 档赢, selftest 每次全月回测这条规则)。
- 日落用天文公式本地算 (NOAA, ±2 分钟), selftest 跟 sunrise-sunset.org 对表。

## 手续费 (2026-07-12 官方核实, 已建模进盈亏)

- **天气类只收 taker 5%** (maker 免费; 结算/赢钱/充提零费)。公式: `费 = 股数 × 5% × p × (1−p)`, USDC 计, 成交时收。
- 买在 0.9~0.995 区间时, 手续费 ≈ **毛利的 ~5%**, 策略成立不受影响:
  - $5 @ 0.97 → 毛利 $0.155, 费 $0.0075, **净赚 $0.147 (≈2.9%/夜)**
  - $5 @ 0.99 → 毛利 $0.051, 费 $0.0025, 净赚 $0.048
  - $5 @ 0.90 → 毛利 $0.556, 费 $0.025, 净赚 $0.531
- 模拟盘盈亏**已自动扣费** (`decide.fee_usd`); 真钱下单库 1.0.2 自动按市场费率签单。
- 注: CLOB 市场对象 `taker_base_fee=1000` 是签名授权上限, 实收按官方 5% 档; 真钱跑通第一单后可对照余额验证扣费口径。

## 已知风险 (为什么不是 100%)

1. 夜间暖锋/焚风把温度顶破当日最高 — 罕见但存在, 降温确认 + 买后盯破档红条报警兜着。
2. 香港半路启动当天数据缺前半天 (1 分钟源只给最新) → 覆盖守卫自动跳过当天, 从次日起正常。
3. 结算源页面出错/改版 — 市场共识护栏兜底 (我们和市场都错才会亏)。
